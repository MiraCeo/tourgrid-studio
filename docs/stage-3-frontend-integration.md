# 阶段三：前端本地转换集成

当前网页保留 Canvas 编辑器的绘图、裁切、导航器、统计、参考图和图纸导出能力，图片导入统一使用浏览器本地固定色板转换。

## 当前实现

- FastAPI 根路径 `/` 直接提供编辑器，前端静态资源与 `/api/v1` 同源。
- 网页仅在浏览器本地转换图片，不会上传用户图片。
- 本地转换使用内置 `natural-64-v2` 固定64色候选色板，支持照片平滑平均、
  像素画中心代表色两种采样方式，以及无抖动、Floyd–Steinberg、Atkinson、
  Bayer 2×2 和 Bayer 4×4。
- 导入主预览在处理后原图和最终色板结果之间切换；24×24真彩采样作为明确
  标注“非最终效果”的辅助参考入口独立提供。像素画采样另有可关闭的24×24
  对齐网格。
- 目标颜色少于64色时，候选色按全画面加权误差的下降量逐步选取，并轻度
  提高高对比边缘格子的权重，减少只按出现次数截断造成的细节色丢失。
- 色板距离仍以加权RGB为主；只有来源像素色彩明确、饱和度较高时，才对误差
  接近的候选颜色附加最高20%的色相偏离惩罚。目标色选择和最终匹配使用同一
  距离，灰阶和低饱和肤色不启用该保护。
- 编辑器和网页转换的输出尺寸统一固定为 24×24。
- 网页转换使用打包的版本化色板副本，后端色板接口用于查询和作品版本校验。
- 后端不再提供图片上传、图片转换或临时预览接口。
- 导入操作纳入统一撤销/重做快照。
- localStorage 使用 schema v4，能够迁移旧版存档并保存来源、色板、转换器版本和参考图状态。
- 裁切后的参考图会在浏览器本地编码为 256×256 WebP Blob，并保存到 IndexedDB；刷新后可恢复参考图、开关和透明度。
- 历史存档中的服务器转换来源仍可恢复和显示。
- 裁切区支持鼠标、单指移动和双指缩放。
- 支持颜色统计、按颜色高亮、逐格复刻进度和整色批量完成；复刻操作只改变本地进度，不修改作品像素。
- 吸管会把画布颜色匹配到最近的固定64色，并在颜料或统计面板中自动选中定位。
- 三种统计排序均展示全部64色，零用量显示为0，同数量按色板位置排序。
- 支持原始尺寸 PNG、16 倍最近邻预览图和图纸导出。
- `S` 创建手动保存点，导出操作统一位于顶部“完成并导出”菜单。画布快捷键在
  输入控件或可编辑内容聚焦时不会响应。

## 本地运行

```powershell
.\.venv\Scripts\python.exe -m backend
```

打开：

- 编辑器：`http://127.0.0.1:8000/`
- API 文档：`http://127.0.0.1:8000/docs`

不要直接双击 HTML 作为日常启动方式。同源运行可以保证静态资源和版本化色板来自同一个服务版本。

## 模块边界

- `storage.js`：存档校验、序列化和旧版本迁移。
- `reference-storage.js`：IndexedDB 参考图 Blob 的保存、恢复和删除。
- `natural-64-v2.js`：浏览器本地转换使用的当前候选64色色板副本。
- `state.js`：编辑器状态、元数据与色板数据。
- `editor.js`：Canvas 绘制、撤销重做和导航器。
- `export.js`：原始 PNG、最近邻预览和图纸。
- `import.js`：图片读取、裁切、本地固定色板转换、重试和参考图。
- `app.js`：工具、色板选择、快捷键及页面控制。

## 验证

```powershell
.\.venv\Scripts\python.exe -m pytest
```

测试覆盖同源编辑器入口、网页仅本地固定色板转换、存档迁移和历史来源兼容、
WebP参考图持久化、裁切重试与触控、原始PNG和最近邻预览导出，以及所有前端
JavaScript文件的语法。API测试明确断言旧服务器转换路由返回404。
