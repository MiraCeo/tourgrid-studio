# 已知限制与后续提醒

以下行为暂时保留，后续继续调整工程保存和撤销模型时需要重新评估。

## 参考图持久化不包含原始图片与裁切状态

裁切后的参考图会在浏览器本地编码为 WebP Blob 并保存到 IndexedDB，参考图开关与
透明度会随 `localStorage` 存档恢复。用户原始图片、裁切位置和裁切缩放比例仍然只在
当前页面会话中保留。

因此刷新页面后可以继续对照已经裁切好的参考图，但不能重新打开原裁切区域进行调整。
如果未来需要恢复完整导入工程，需要另外保存原始图片 Blob 和裁切参数，并评估存储
空间、隐私说明和清理策略。

## 撤销区分文档状态与视图状态

撤销和重做快照会保存固定 24×24 像素矩阵、文档元数据、编辑器色板和当前参考图
资源。导入与清空均可完整恢复对应的像素和参考图，历史上限为100步；不再被历史引用
的参考图 WebP 会从 IndexedDB 自动清理。

以下辅助视图状态不进入撤销栈：

- 参考图开关和透明度；
- 裁切状态；
- 画布缩放与平移位置。

这是当前明确采用的产品语义：撤销恢复作品文档，不改变用户正在使用的观察方式。
如果未来决定让视图状态也参与撤销，需要同步修改快照结构、浏览器回归条目和存储
资源评估。
