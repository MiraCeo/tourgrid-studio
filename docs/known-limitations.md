# 已知限制与后续提醒

以下行为暂时保留，后续继续调整工程保存和撤销模型时需要重新评估。

## 参考图不会随存档恢复

当前 `localStorage` 存档会保存像素矩阵、网格尺寸、来源和版本元数据，但不会保存：

- 导入图片或裁切后的参考图；
- 参考图开关状态；
- 参考图透明度。

因此刷新页面后可以恢复像素画，但参考图和对应控制状态不会恢复。

后续若要求完整恢复工程，优先考虑使用 IndexedDB 保存参考图 Blob，不建议把大型
Data URL 写入 localStorage。

## 撤销不会完整恢复参考环境

撤销和重做快照会保存像素矩阵、网格尺寸、文档元数据和编辑器色板，但不会保存：

- 当前参考图；
- 参考图开关和透明度；
- 裁切状态；
- 画布缩放与平移位置。

因此撤销导入可以恢复像素内容，但辅助参考环境可能仍保持后一次导入的状态。

后续若扩展为完整工程撤销，需要先定义哪些辅助视图属于文档状态，再统一扩展快照
结构、存档迁移和内存占用限制。
