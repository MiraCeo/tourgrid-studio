# 已知限制与后续提醒

以下行为暂时保留，后续继续调整工程保存和撤销模型时需要重新评估。

## 参考图持久化不包含原始图片与裁切状态

裁切后的参考图会在浏览器本地编码为 WebP Blob 并保存到 IndexedDB，参考图开关与
透明度会随 `localStorage` 存档恢复。用户原始图片、裁切位置和裁切缩放比例仍然只在
当前页面会话中保留。

因此刷新页面后可以继续对照已经裁切好的参考图，但不能重新打开原裁切区域进行调整。
如果未来需要恢复完整导入工程，需要另外保存原始图片 Blob 和裁切参数，并评估存储
空间、隐私说明和清理策略。

## 撤销区分文档状态与视图状态

撤销和重做快照会保存固定 24×24 像素矩阵、文档元数据、编辑器色板和当前参考图
资源。导入与清空均可完整恢复对应的像素和参考图，历史上限为100步；不再被历史引用
的参考图 WebP 会从 IndexedDB 自动清理。

以下辅助视图状态不进入撤销栈：

- 参考图开关和透明度；
- 裁切状态；
- 画布缩放与平移位置。

这是当前明确采用的产品语义：撤销恢复作品文档，不改变用户正在使用的观察方式。
如果未来决定让视图状态也参与撤销，需要同步修改快照结构、浏览器回归条目和存储
资源评估。

## 复刻进度按作品逐格保存在当前浏览器

复刻模式不会修改作品像素。选择一种颜色后，可以点击或连续拖动其未完成高亮格，
将对应坐标标记为已涂色。右侧整色复选框仅在该颜色的全部现有格子都完成时勾选：
未勾选时点击会完成全部格子，已勾选时点击会把全部格子恢复为未涂色。

进度以作品像素指纹和格子坐标保存在当前站点的 `localStorage`。旧版按颜色保存的
完成记录会在首次读取时迁移为逐格记录。编辑作品时，颜色发生变化的已完成格会恢复
为未涂色，其他坐标的进度继续保留；给原本已完成的颜色新增格子后，整色复选框会
自动恢复为未勾选状态。

这些进度不会上传服务器，也不进入作品撤销栈。它们只在相同浏览器和相同站点来源
下长期保存；更换域名、端口、浏览器或设备不会自动迁移，清除站点数据也会删除进度。

## 服务器图片转换子系统已经移除

从0.3.0开始，服务器图片转换子系统已经移除，包括转换CLI、Pyxelate核心、
图片上传、转换worker、临时预览接口及科学计算生产依赖。

当前产品边界是：

- 图片读取、裁切、官方色板映射和参考图保存均由浏览器本地转换完成；
- FastAPI负责健康检查、色板查询、不可变作品分享和管理员管理接口；
- PostgreSQL保存作品像素索引、元数据、永久封禁、删除墓碑和管理审计记录；
- Redis保存浏览去重、共享限流和临时封禁等带TTL状态；
- 历史前端存档中的 `converterVersion` 字段继续兼容，但不表示服务器仍有转换接口。

如果未来重新引入服务器转换，必须设计新的版本化接口、资源隔离和独立部署方案，
不能恢复已经删除的旧接口并假设其仍受支持。
