项目公告

欢迎使用 Tourgrid Studio

01

项目介绍

Tourgrid Studio 是一款非官方的 24×24 像素画编辑器。 它可以将图片转换为固定 64 色范围内的像素画，并提供逐像素编辑、 颜色统计、参考图与作品导出功能。

本项目与相关游戏、活动及其权利人不存在隶属、合作、授权或背书关系。

02

使用指南

  1. 导入点击顶部“导入”，选择图片并确认裁切区域。
  2. 转换浏览器会在本地生成 24×24 像素图，图片不会上传。
  3. 编辑从右侧颜料中选色后直接绘制；选择白色即可擦除。
  4. 复刻在“复刻”中按颜色高亮格子，并勾选记录游戏内完成进度。
  5. 查看使用左侧参考图与缩放控制辅助对照细节。
  6. 导出完成编辑后，从顶部导出所需的图片或图纸。
03

快捷键帮助

B切换到画笔
E切换到白色橡皮
I切换吸管取色
M切换移动画布模式
按住 H临时拖动画布
G显示或隐藏辅助线
0让画布适应当前视口
S创建手动保存点
Ctrl/Cmd + Z撤销
Ctrl/Cmd + Y重做
Ctrl/Cmd + Shift + Z重做
Esc关闭弹窗或退出当前工具
Enter在分享输入框中读取作品
方向键聚焦导航缩略图后移动视口

输入框、下拉框、文本区域、按钮、链接或可编辑内容聚焦时，画布快捷键不会响应， 文字撤销和浏览器快捷键仍按原有方式工作。

04

隐私与作品保存

导入图片、裁切和颜色转换均在浏览器本地完成，原图和参考图不会上传。 发布作品时，服务器仅接收 24×24 像素索引、色板版本以及你填写的标题和作者。

浏览次数使用随机匿名 Cookie，并通过临时键进行时间窗口去重；服务日志和 滥用防护可能处理访问 IP，永久封禁记录会保存在数据库中。

作品发布后不可自行覆盖或修改，并会长期保存在服务器中；请勿在标题或作者栏 填写真实姓名、联系方式等不希望公开的信息。

05

内容规则与联系

请勿发布违法违规、侵害他人权利、包含个人敏感信息或明显用于骚扰的内容。 管理员可以隐藏或永久删除违规作品，处理原因会向分享码访问者公开。

如需举报违规或侵权内容、申请删除作品，或反馈隐私问题，请通过 项目 GitHub Issues 联系维护者。提交时请提供分享码和必要说明，不要公开个人敏感信息。
